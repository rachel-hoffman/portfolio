The JABA app is a mobile platform that assists college athletes with NIL brand deals. In order to further this central goal, we looked to integrate a calendar feature within the app. This feature aims to increase user productivity and transparency.

I was selected by upper management to tackle this project. I loved being given complete creative control over my workflow and design process, completing the early research and design phases myself.

My Work

Competitor Analysis

For this app, the calendar was not meant to be a feature that differented us. Rather, we aimed to create a foundational and reliable feature. Any confusion risks missed meetings or deadlines, which would quickly erode trust. To understand existing user expectations, I analyzed established products.

In total, I reviewed 16 mobile calendar apps, drawing input from my team on the tools they personally use. My comparisons helped identify common patterns and standout features to explore during ideation.

User Flow Diagram

I created a user flow diagram to map out the specific screens the flow would need, the back end processes affecting the flow, and the user decisions affecting the flow. This was a vital step to get my thoughts out on “paper,” and start to understand the user experience I wanted to create.

Design Mockups

The final deliverable for this project was UI mockups that I handed off to our UI designer for finalized designs.

I created this deliverable not worrying about the specific dimensions of screen size, margins, padding, etc. Instead, I focused on delivering a functioning design with a clear system behind it. I delivered an experience that will be intuitive for smartphone users familiar with other calendar features.

Final Design

This project taught me the full complexity of designing a complete user experience. In total, I designed over 30 screens, most of which are in the user flow shown below. In addition to this, I created a mirrored version fro the admin app, which is seperate from the student app. I also created the desktop version for both the student and admin platforms.
