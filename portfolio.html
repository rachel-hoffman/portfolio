This project blended design and development, two parts of product design I don't often get to work on simultaneously. I recently completed a Responsive Web Design certification, and this became the perfect opportunity to put those skills into practice.

I planned, designed, coded, and managaged the process of every part of this project. I used HTML, CSS, and JavaScript to create the final product, and I handled all the hosting, file management, and updates through GitHub. This allowed me to create something something that feels fully mine.

My Work

Initial Brainstorming

I had this initial idea of making a highly interactive portfolio that looked almost like a video game. I thought about having the user even interact by moving a character around with WASD.

Ultimately though, I landed on this idea of making my website look like a desktop. I wanted it to look as if the user is getting a window into what my computer looks like, and to let them interact with the files that are on it.

Design Work

I had a lot of fun with the design of this website. I even decided to draw all of my own pixelated icons using Procreate, which makes the site super personal to me.

HTML, CSS, and JS

I coded the site by hand, which was a really great opportunity to bring together the skills I have developed over the years.

I focused on responsiveness and had fun with the design. I even challeneged myself with small projects like adding a light mode, and having an explosion effect.

GitHub Hosting

An important choice I made is that I self-hosted this site on GitHub Pages. I moved my custom domain from Wix to Github, and with it regained control over my work. No longer relying on subscriptions, I now have complete control of a site I can keep on evolving as I learn and grow.

Final Product

This website brought together my foundations in both front-end development and UX design. I will continue to add new features and experiment with new tactics on this site, but I'm beyond happy with where it is today. The foundation is functional and responsive, reflecting both my design style and technical skillset.

This project is more than just a portfolio. It’s proof to myself that I can design something, code it, deploy it, and maintain it independently. It represents creative freedom, technical growth, and the start of me building things on the web not just as a designer, but as a creator. Stay tuned for more!
